# Aprendizaje de Python

Repositorio personal para guardar scripts, ejercicios y el avance del curso (`progreso.md`) entre dos computadoras.

## Cómo trabajar entre dos computadoras

### Al empezar en una computadora (traer últimos cambios)
```bash
git pull
```
Luego abre esta carpeta como tu **workspace** en Antigravity y escribe:
> `Lee progreso.md y seguimos desde ahí`

### Al terminar tu sesión (subir tus cambios)
```bash
git add .
git commit -m "Avance: <tema o ejercicio>"
git push
```
